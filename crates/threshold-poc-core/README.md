# Threshold PoC core

**Experimental shared implementation for five proof-of-concept Ootle templates.**

This is a separate fork of the published v1 logic, with explicit matched and community-only funding modes. It is not a published template by itself. Terms use experimental version 100.

Only compile checks and four lightweight term/encoding tests have run. These do not exercise ledger execution, private transfers, or recovery. The existing client and recovery packages are not compatible.

See the [template guide](../../docs/campaign-templates.md) for APIs, example terms, and unfinished qualification.
