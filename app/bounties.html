THE DECISION RULE

1 of 1 or 2 of 3. Set before funding.

A council member creates and can revise the request. The reviewer list and quorum are adjustable until funding; funding freezes them. A matching quorum approves an award or a no-work closure. ADDING A BOUNTY

How does it appear here?

For this demo, the client creates and funds a component, records its address in a small public list, and the site build publishes that list. The board then reads each component’s current state from Ootle every 30 seconds. A new address needs a list update and site deployment before it appears.

A future council-controlled on-chain registry could hold approved component addresses and name labels. The board could read that registry so newly registered bounties appear without a site deployment. Scanning every component made from this template would also include unauthorised lookalikes.

Each card requires the Esmeralda indexer’s verified flag and the expected template address. The indexer is a data source, not an independent consensus light client. This page cannot submit transactions.
